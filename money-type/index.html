돈BTI 테스트

나의 소비 성향을 16가지 동물로 알려 드려요.

돈BTI는 이렇게 나눠요

  • 모으는 / 쓰는: 돈이 생기면 먼저 모으는지, 지금 쓰는 게 더 행복한지
  • 계획적 / 즉흥적: 예산과 계획을 세우는지, 그때그때 감으로 쓰는지
  • 안전제일 / 도전: 확실한 이자가 좋은지, 수익을 위해 도전하는지
  • 나를 위해 / 함께: 나에게 쓸 때가 좋은지, 다른 사람과 나눌 때가 좋은지
